## ⚡ Quick Commands

```bash
# Start Backend
cd backend && .venv\Scripts\python.exe -m uvicorn app.main:app --port 8000

# Start Frontend
cd frontend && npm run dev

# Run Tests
cd backend && python test_api_smoke.py
```
